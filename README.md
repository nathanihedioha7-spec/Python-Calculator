#Python Calculator

A simple command-line calculator built in Python that performs basic arithmetic operations. This project was created to practice core programming concepts such as user input handling, conditional logic, loops and basic error handling.

---

#Features

- Addition, subtraction, multiplication, and division
- Continuous calculations using a loop
- Handles division by zero errors
- Simple and user-friendly command-line interface

---

#Language Used

- Python
